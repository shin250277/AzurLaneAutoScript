# Depths of the Astrarium / 몽광의 아스트라리움

Map definitions and Bonhomme Richard templates were imported from
[LmeSzinc/AzurLaneAutoScript](https://github.com/LmeSzinc/AzurLaneAutoScript/tree/c2eb13878bd9816ef3e6d23ce84f7263d1d18fd3/campaign/event_20260813_cn)
at commit `c2eb13878bd9816ef3e6d23ce84f7263d1d18fd3`.
The original repository license applies. Only trailing whitespace was normalized.

KR registration uses the localized event title. Offline checks cover imports,
map dimensions, boss spawn definitions, template availability and registration.
They do **not** verify KR stage recognition, map layout equivalence or combat.
Do not substitute these maps for another event or assume that D3/SP is unlocked.

Run offline checks with `python -m unittest dev_tools.test_astrarium_maps`.
