# 한국 서버 — 템페스타와 안개회랑

검증일: 2026-11-09. 이벤트 구현: `event_20261022_cn`.

## T6 파밍 시작

1. Alas.exe의 `alas` → 이벤트 → 이벤트 파밍을 연다.
2. 이벤트 이름이 `템페스타와 안개회랑`, 해역 이름이 `T6`인지 확인한다.
3. 주회 모드·편성 고정·자동 공략은 켜고, 고효율 작전 지령서는 끈다.
4. 해역 달성도는 `계속 실행`, 연속 공략 활성화는 끈다. 해역 실행 횟수에는 원하는 **양수**를 넣는다. 0은 횟수 무제한이므로 단회/시험에는 쓰지 않는다.
5. 연료 하한1000, 기존 함대·컨디션 보호·잠수함 미사용·퇴역 기준을 유지한다.
6. 작업 활성화를 켠 뒤 개요에서 시작한다. 예약된 의뢰 등 정상 정기 작업은 먼저 처리될 수 있다.

횟수가 소진되면 이벤트 작업은 비활성화된다. 다시 돌릴 때는 횟수를 새로 지정한 다음 활성화한다. 도크 부족 시 기존 일괄퇴역 기준에 해당하는 함선이 없으면 사용자가 공간을 확보해야 한다. 유료 확장이나 기준 완화는 필요하지 않다.

## SP

`이벤트 일일 → 이벤트 일일 SP`는 T6 파밍과 별도 작업이다. T1~T6를 열어도 SP 전용 함대 편성이 자동으로 채워지지는 않는다. 게임 내 SP 편성에서 사용할 함선을 배치하고 표시된 평균 레벨105 초과 조건을 충족해야 한다. 11/9 최초 확인에서는 두 함대 모두 비어 있어 안전 중단했다. 조건 미충족 상태로 반복 실행하지 않는다.

SP는 일일 단회 작업이며, 검증용 임시 활성은 종료 후 해제한다. SP 전투·클리어 여부는 아래 검증 기록을 따른다.

## 검증 범위

11/9 15:20 기준 T1~T6 개방 및 T6 연속2회 파밍·자동 재출격·횟수0 종료·메인 복귀를 확인했다. 이벤트 검증용 활성은 꺼져 있다. SP는 빈 전용 편성 때문에 전투 검증 전이다.

상세 결과는 `KR_VALIDATION_2026-11-09.md`에 기록한다. T1~T6 첫 클리어/자동 단계 전환과, T6 반복 파밍/횟수 종료, SP 클리어는 서로 다른 판정이다. 드물게 나타나는 팝업 전체나 장기간 무오류 운전을 보장하는 문서가 아니다.
