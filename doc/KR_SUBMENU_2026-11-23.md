건조 대열은 정상 판별했다. 지원 탭의 금색 '지원신청'을 '건조 개시'로 오인하는 오류가 재현됐다. 한국어 버튼의 판별 영역과 기준색만 분리했다. 기존 클릭 위치는 유지했다. 건조 세 종류(소형함·중형함·특형함)와 지원 화면에서 수정본을 재생해 두 판별기가 동시에 참이 되지 않음을 확인했다. 원본 계정 정보가 없는 버튼 영역만 별도 회귀 표본으로 보관한다. 건조 제출, 실제 상대 변경, 전투, 의뢰 파견, 상점 구매는 이 검사에 포함하지 않는다. 마우스가 글자를 가린 캡처는 버튼 교체의 근거로 쓰지 않았다.

전체 비교는 실행본의 `module/**/assets.py`에서 Button 정의 1,356개를 열거했다. 90장(같은 메뉴를 다시 연 화면 포함)과 동일 좌표를 대조해 111개에서 시각적 일치 후보를 찾았다. 1,152개는 이 방법에서 일치하지 않았고, 93개는 단색·크기·형식 등의 이유로 비교 대상에서 제외했다. 결과는 버튼의 실제 사용 가능 여부가 아니다. 움직이는 버튼, OCR, 색상만으로 구분하는 상태, Template 객체는 별도의 검사 대상이다.

숙소·데일리 화면을 더한 94장에서 상하좌우 20픽셀까지 확장한 결과는 동일 위치 후보 113개, 주변 위치 추가 후보 13개, 시각적 근거 없음 1,137개, 비교 제외 93개다. 같은 뒤로가기 아이콘이나 확인 글자가 다른 화면에도 나올 수 있으므로 후보만으로 교체하거나 기능 통과로 표시하지 않는다.
