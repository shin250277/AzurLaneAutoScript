# 한국 서버 사용 인계 — 2026-11-09

이 문서는 모든 옵션의 검증 목록이 아니라, 실제 성공한 범위로 혼자 사용하는 안내다. 기존 함대·보호·구매 필터를 유지한다. 이 문서를 작성하며 설정을 바꾸거나 작업을 켜지 않았다.

## 시작과 중지

1. 에뮬레이터와 게임을 실행하고 점검/업데이트/로그인을 마친다.
2. `Alas.exe`에서 기존 `alas` 설정을 선택한다. 별도 `kr` 설정으로 바꾸지 않는다.
3. 필요한 작업만 열어 `작업 활성화`를 켠다. 기존 정상 정기 작업은 유지한다.
4. `개요 → 시작`. 예약 시각이 된 작업부터 실행하므로 다른 정기 작업이 먼저 처리될 수 있다.
5. 종료하려면 `개요 → 중지`. 작업을 이후에도 실행하지 않으려면 해당 작업의 활성화도 끈다. 중지 버튼과 예약 비활성화는 다르다.

유료 재화·확장 구매는 켜지 않는다. 연료 하한1000, 함대/컨디션/체력 보호, 잠수함 미사용과 기존 퇴역 기준을 유지한다. 도크가 차면 기존 기준 일괄퇴역만 사용한다. 해당 기준의 대상이0이면 공간을 직접 확보하며 기준을 완화하거나 유료 확장하지 않는다.

## 성공 이력은 있지만 소비 범위를 알고 따로 켤 기능

- 대형작전 상점: 기존 비유료 필터 구매/종료 확인. 일반 재화도 소비한다.
- 기록 해역: 장치 구매→연속임무→보상→구매 재고 없음→종료 확인. 보유 좌표1개만 쓰는 기능이 아니며 일반 교환 재화로 장치를 추가 구매한다. 상시 활성화는 기본 조합에서 제외한다.
- 본인 META: 기존1회 공격/종료 확인. 격파 보상까지 확인한 것으로 확대하지 않는다.
- 소형 건조/기존 지휘냥 구매/기존 금화 선물: 각각 기존 한정 설정의 성공 이력만 있다. 일상 사용에 필요 없으면 켜지 않는다.
- 일반/길드/훈장 상점: 기존 필터의 성공 범위만 사용하며 모든 상품 분류·구매를 보장하지 않는다.
- 대형작전 일일: 과거 작업 종료 이력은 있으나 모든 임무 기하/좌표 오류 해결을 보장하지 않으므로 기본 인계 조합에는 넣지 않는다.

## 현재 꺼 둘 기능: 실제 결함/미해결 보호 문제

- **섬 일반 생산**: 일부 시설의 이름 판독 실패로 안전 중단한다. 수령/일부 생산 시작 성공과 전체 정상 운용은 다르다.
- **섬 시즌 자동 연계**: 현재 시즌 목표 동기화는 통과했지만 보상 수령 연결은 미완료. 일반 생산 결함도 해결되지 않았다.
- **이벤트 상점 자동 구매**: 신규3상품 분류 미확인. `도구 → 이벤트 상점 판독(구매 없음)`은 사용 가능하며31품목 스캔 종료 확인.
- **META 지원**: 일반 지원은 성공했으나 특정 누적 보상 카드 수정의 동일 실기 확인이 남았다.
- **위험도1 레벨링·지휘냥 파밍**: 반복 종료/AP 보호 영향 정리가 필요하다.
- 요새/월간보스/심연은 현재 전투력·적응도·함대 조건을 확인하기 전 강제 실행하지 않는다.

새 개발함/지휘냥 강화 대상/공유 길드/생산계획 실제 내보내기 등은 기존 설정을 유지한다. 대상 미정·미개방·희귀 예외는 프로그램 전체의 사용을 막는 사유가 아니다.

## 오류가 나면

- 반복 재시작하지 말고 실패 작업을 비활성화한다. 기존 설정을 임의로 낮추지 않는다.
- 오류 시각·작업 이름과 로컬 `log`의 해당 날짜 로그를 남긴다. 유료 구매나 퇴역 기준 변경으로 해결하지 않는다.
- 인계한 다른 작업까지 반드시 못 쓰는 것은 아니다. 화면이 정리되지 않았으면 게임 메인 복귀 후 정상 작업만 시작한다.

## 개발 범위 고정

시즌과 무관한 생산시설 진입/레시피 선택/재고·재료 판독/보호 재고/생산 시작/완료 수령은 **지금 수정할 대상**이다. 11월19일 대기는 신규 시즌 과제·품목·새 화면에만 적용한다. 상시 기능 결함을 시즌 대기로 분류하지 않는다. 이미 성공한 기능의 희귀 분기를 전부 다시 돌리느라 인계를 미루지 않는다.
