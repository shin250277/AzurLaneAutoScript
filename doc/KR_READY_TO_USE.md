# 한국 서버 사용 인계 — 2026-11-20 갱신

11월20일 신규 섬 시즌 데이터·화면 인식 보완을 진행했다. 아래 실기 성공 이력은 해당 날짜/조건의 결과이며, 이벤트 종료 뒤에도 해당 이벤트가 계속 열린다는 뜻이 아니다. **템페스타와 안개회랑 T6/SP는 과거 검증 이력**이므로 현재 게임에서 이벤트가 열려 있는지 확인한 뒤 사용한다. 옛 이벤트 설정을 새 이벤트에 그대로 실행하지 않는다.

신규 겨울 시즌은30개 임무·신규 품목·생산식·씨앗 구매 데이터가 추가됐으며, 11월20일10:31 실제 전체 판독2회 일치와16종 생산 목표 동기화/정상 종료를 확인했다. 보호를 유지하는 제출 처리도 추가했지만 **현재 수령 가능한 과제가 없어 실제 제출/보상 수령까지 통과했다고 하지는 않는다**. 오늘 상세 결과는 `KR_VALIDATION_2026-11-20.md`에 기록한다.

이 문서는 모든 옵션의 검증 목록이 아니라, 실제 성공한 범위로 혼자 사용하는 안내다. 기존 함대·보호·구매 필터를 유지한다. 검증용 임시 설정과 원복 여부는 당일 검증 문서에 별도로 기록한다.

## 시작과 중지

1. 에뮬레이터와 게임을 실행하고 점검/업데이트/로그인을 마친다.
2. `Alas.exe`에서 기존 `alas` 설정을 선택한다. 별도 `kr` 설정으로 바꾸지 않는다.
3. 필요한 작업만 열어 `작업 활성화`를 켠다. 기존 정상 정기 작업은 유지한다.
4. `개요 → 시작`. 예약 시각이 된 작업부터 실행하므로 다른 정기 작업이 먼저 처리될 수 있다.
5. 종료하려면 `개요 → 중지`. 작업을 이후에도 실행하지 않으려면 해당 작업의 활성화도 끈다. 중지 버튼과 예약 비활성화는 다르다.

유료 재화·확장 구매는 켜지 않는다. 연료 하한1000, 함대/컨디션/체력 보호, 잠수함 미사용과 기존 퇴역 기준을 유지한다. 도크가 차면 기존 기준 일괄퇴역만 사용한다. 해당 기준의 대상이0이면 공간을 직접 확보하며 기준을 완화하거나 유료 확장하지 않는다.

## 신규 섬 시즌: 현재 동작과 제한

- `도구 → 섬 주문·시즌 화면 검사`: 주문/시즌 화면을 읽고 복귀한다. 제출·구매·목표 변경을 하지 않는다.
- `섬 → 섬 시즌 임무`: 현재 시즌의 30개 임무·진행도·수령 여부를 두 번 읽고 일치할 때 `시즌 목표`를 동기화한다. 메뉴/보호 재고를 덮어쓰지 않는다.
- 기존 `섬 생산`은 저장된 시즌 목표도 읽어 생산 후보와 재료 보호량에 반영한다. 목표 동기화와 생산을 위해 보호 설정을 낮출 필요는 없다.
- **시즌 과제 일괄 수령은 물품 제출을 겸한다.** 완료된 과제 전체의 합산 소비 후에도 보호 재고와 식당 예약분이 남는 경우에만 한 번 제출하는 처리를 추가했다. 진행도가 불명확하거나 보호량을 침범하면 제출하지 않는다. 제출 후 수령 확인이 불명확하면 영수 기록을 남겨 재실행도 차단한다. 이 경로의 실제 수령 확인 여부는 아래 검증 문서와 구분해서 본다.
- `Unresolved KR season claim`으로 중지되면 반복 시작하거나 저장된 기록을 지우지 않는다. 게임의 해당 과제 수령 상태와 로컬 오류 로그를 확인해야 한다.
- 장시간 생산이 실제 시작되면 다음 완료 시각까지 작업 없음은 정상이다. 다만 로그에 오류/수동 중지/예약 비활성화가 있으면 생산 대기와 구분한다.

## 성공 이력은 있지만 소비 범위를 알고 따로 켤 기능

- 대형작전 상점: 기존 비유료 필터 구매/종료 확인. 일반 재화도 소비한다.
- 기록 해역: 장치 구매→연속임무→보상→구매 재고 없음→종료 확인. 보유 좌표1개만 쓰는 기능이 아니며 일반 교환 재화로 장치를 추가 구매한다. 상시 활성화는 기본 조합에서 제외한다.
- 본인 META: 기존1회 공격/종료 확인. 격파 보상까지 확인한 것으로 확대하지 않는다.
- 소형 건조/기존 지휘냥 구매/기존 금화 선물: 각각 기존 한정 설정의 성공 이력만 있다. 일상 사용에 필요 없으면 켜지 않는다.
- 일반/길드/훈장 상점: 기존 필터의 성공 범위만 사용하며 모든 상품 분류·구매를 보장하지 않는다.
- 대형작전 일일: 과거 작업 종료 이력은 있으나 모든 임무 기하/좌표 오류 해결을 보장하지 않으므로 기본 인계 조합에는 넣지 않는다.

## 기본 조합과 구분할 기능·조건

- **섬 시즌 임무**: 겨울 목표 동기화는 사용 가능하다. 보호 재고를 유지하는 제출 처리도 구현·회귀 검사했지만, 실제 수령 확인은 완료된 미수령 과제가 없어 남았다. 이것은 시즌 시작 대기나 목표 동기화 불가를 뜻하지 않는다. 생산계획의 메뉴·보호 설정 자동 덮어쓰기는 사용하지 않는다.
- **이벤트 상점 자동 구매**: 신규3상품 분류 미확인. `도구 → 이벤트 상점 판독(구매 없음)`은 사용 가능하며31품목 스캔 종료 확인.
- **META 지원**: 일반 지원은 성공했으나 특정 누적 보상 카드 수정의 동일 실기 확인이 남았다.
- **위험도1 레벨링·지휘냥 파밍**: 반복 종료/AP 보호 영향 정리가 필요하다.
- 요새/월간보스/심연은 현재 전투력·적응도·함대 조건을 확인하기 전 강제 실행하지 않는다.

새 개발함/지휘냥 강화 대상/공유 길드/생산계획 실제 내보내기 등은 기존 설정을 유지한다. 대상 미정·미개방·희귀 예외는 프로그램 전체의 사용을 막는 사유가 아니다.
