# 한국 서버 점검 후 재시작 검증

- 20:54 UI에서 재시작 다음 실행 입력을 비워 즉시 실행을 요청했으나, 스케줄러 시작 시 첫 재시작을 무조건 건너뛰었다. 이어진 의뢰는 연결 끊김 화면에서 `Game page unknown`으로 중단되었다.
- `alas.py`에서 UI 즉시 실행 값(2020-01-01)은 첫 재시작 생략 대상에서 제외했다. 일반 정기 재시작의 기존 생략 동작은 유지한다.
- 회귀검사: 명시적 재시작 실패를 수정 전 재현한 뒤 3개 정책 검사 통과, 전체 discovery 188개 통과. 이 검사는 스케줄러 조건식 검사이며 게임 로그인 검증과 구분한다.
- 20:57:55 실제 Alas.exe 스케줄러 `Restart` 시작, `APP RESTART`, 한국 앱 stop/start 로그 확인. 수정된 UI 요청이 실제 게임 재실행으로 연결되는 것은 실기 확인했다.
- 재실행 후 게임은 586.9 MB 리소스 다운로드 확인 팝업을 표시했다. 접속 완료/메인 진입은 아직 검증하지 못했다. 자동 로그인은 이 팝업을 처리하지 못해 스케줄러를 수동 중지했다. 유료 재화는 사용하지 않았다.
- 17시의 오래된 연결 끊김 팝업을 접속 불가 근거로 삼은 이전 판단은 부적절했다. 최신 앱 재실행 상태를 기준으로 판단해야 한다. 20시까지 전체 검증 목표는 달성하지 못했다.
