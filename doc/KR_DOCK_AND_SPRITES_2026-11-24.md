# 11월 24일 한국 서버 이미지 대조 결과

한섭 도크에서 배경까지 흰색으로 이진화되어 함대 숫자가 소실되는 문제를 확인했다. 일본 서버의 이진화 방식을 변경하지 않고, 한국 서버의 1·2·3만 실제 표식에서 잘라낸 컬러 숫자로 대조한다. 유사도뿐 아니라 차순위 숫자와의 점수차 및 픽셀 색 차이를 확인한다. 11월 22일 도크 14척 전체 일치, 수정용 원본과 별개인 8월 13일 도크 14척 전체 일치(미편성 1척 포함). 함선을 퇴역시키거나 설정을 변경한 실험이 아니다.

| 범위 | 실제로 입증한 내용 |
|---|---|
| 이동형 정의 전체 448개 | [개별 파일과 해역 연결표](KR_SPRITE_PARITY.csv). 최초 검색 47개 후보·401개 미검출. 그 401개 중 347개는 CN·EN·JP·TW 네 파일과 바이트 단위 동일. 공통 파일이라는 증거이지 한섭 화면 출현의 증거는 아니다. |
| 나머지 54개 | [재생 결과](KR_REGIONAL_SPRITE_REPLAY.csv). 한섭 저장 화면 484회 대조(중복 방문 가능); 엄격한 색상·상관 검사에서 15개 후보. 미검출 39개는 작동 실패 판정이 아니다. 초기 표와 추가 표의 기준은 서로 다르다. |
| 작전문서 입구 | 실제 사용되는 입구 판독기로 문서 51종, 화면 슬롯 54개 및 음성 장면을 재생해 오판 0건. 입구 인식이 각 해역 출격 완료를 의미하지 않는다. |
| 연구 | 21:56 상세 4장과 대기 1장 판독. 대기열이 실행 1·대기 3·빈칸 1에서 실행 1·대기 4가 됐고 S9-G-4 선택 후 21:57:11 작업 종료, 21:57:13 메인 복귀. 대기열의 실행 표시는 카드 중앙의 RUNNING 글자를 검증한 것으로 세지 않는다. |
| 개발 도크·대형작전 | [기능 확인표](KR_FEATURE_MATRIX.md)의 Shipyard/OpsiGeneral 참조. 보호 분기 오프라인 검사이며 새 대상 선택·유료 구매 없음. |

전체 오프라인 회귀 905개 통과(337.140초). 현재 화면과 저장된 증거에 없는 4~6함대 표식·출전/의뢰 표식, 매복 결과·세이렌 포획 등 특수 상태는 이미지 교체 근거가 없다. 해당 해역/함선/상태가 실제로 표시될 때 확인한다. 운송의 신규 출발 3건은 21:32 정상 종료 뒤 23:33:57부터 재확인 가능하다. 기존 운송 보상 수령과 신규 3건의 만기 수령은 구분한다.
