## 전수 목록의 의미

[개별 이미지 정의 목록](KR_ASSET_EVIDENCE_2026-11-24.csv)은 생성된 버튼·템플릿 1,798개 각각의 서버 매핑과 위치 비교 결과다. 첫 묶음 404장, 추가 묶음 213장(일부 중복)에 대한 자동 비교로, 각 버튼의 실행 테스트가 아니다. 묶음 사이에 교체한 자산이 있어 수정 항목은 위의 **실행 코드로 다시 재생한 결과**를 우선한다.

- `visual_candidate` / `nearby_visual_candidate`: 동일 또는 주변 위치에 비슷한 이미지가 있었다. 다른 화면의 동일 아이콘도 일치할 수 있다.
- `no_visual_evidence`: 이 위치 검사에서 증거 없음. 고장 또는 이벤트 전용이라는 뜻이 아니다.
- `not_scanned` / `outside_fixed_scan`: 단색·형식 등으로 제외 또는 고정 위치 버튼이 아닌 템플릿. 이 CSV만으로 호환 또는 비호환을 판정하지 않는다.
- `source_uses`: 소스에서 명확히 추적된 직접 용도다. 예를 들어 OCR 자르기나 클릭 좌표는 이미지가 일치하지 않아도 정상일 수 있다. 간접 참조·동적 호출을 모두 해결한 것은 아니다.

설정 번역 키 1,920개를 기준 언어와 대조했다. 그대로 노출되던 전과 상점 '미보유 함선 구매' 이름·도움말을 번역했다. 구매 설정값은 바꾸지 않았다. 지원 작전문서 48개에 대해 한섭 카드에 표시된 제목을 선택 목록에 적용했고, 동일 영문 제목으로 연결되는 기존 이벤트 항목에도 반영했다. 번역은 표시 이름만 바꾸며 캠페인 ID는 변경하지 않는다.

### 상점 상품과 지휘냥 추가 재생

- 매점(일반) 4종, 전과 2종, 코어 1종은 기존 템플릿으로 이름 대신 숫자 ID가 나왔다. 실제 한섭 진열 화면의 상품 아이콘만 추가했다. 일반·전과의 20칸 이름과 코어 성정 유닛을 다시 확인했다.
- 대함대·코어 가격은 재화 아이콘 일부가 숫자 7로 읽히는 사례가 있었다(20→720, 35→735 등). 한섭에서 해당 아이콘을 찾았을 때만 가격 OCR 시작점을 이동한다. 일반·전과·대함대·코어 각 10칸의 숫자와 통화가 일치한다. 구매·필터·보호 설정은 변경하지 않았다. 코어 장비 전부에 구매 필터가 있는 것은 아니다.
- 지휘냥 획득 연출 스킵은 실제 획득 화면에서만 모의 입력을 요청했고, 대기열 및 비교 메뉴 82장에는 요청하지 않았다. 대기열 0/9, 일괄 선택·훈련 시작 버튼과 메인 잔여 15/15·코인 21600을 판별했다. 구매·훈련·소비는 실행하지 않았다.
