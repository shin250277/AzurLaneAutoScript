# 한국 서버 일상 사용 안내

이 안내는 검증된 일상 기능의 운용 범위다. 모든 기능·희귀 상황의 실기 완료를 뜻하지 않는다.

## 시작과 중지

1. 실제 `Alas.exe`에서 `alas` 프로필을 선택한다.
2. `개요`의 `시작`을 누른다. 대기 중에는 다음 예약 시각까지 기다리는 것이 정상이다.
3. 중지하려면 같은 위치의 `중지`를 누른다. 오류가 반복되면 시작을 연속으로 누르지 말고 마지막 오류를 확인한다.

## 도크와 재화

- 사용자의 2026-10-22 승인에 따라 ALAS 퇴역 방식은 `일괄 퇴역`으로 연결한다. 게임 내 일괄퇴역 기준과 보호 설정은 변경하지 않는다.
- 한국 서버에서 일괄퇴역 대상이 없으면 필터를 넓히지 않고 중단한다. UR 경고도 안전 중단 대상이다. 이때만 사용자가 도크/대상 조건을 확인한다.
- 보석·현금성 재화·도크/창고 확장 구매는 하지 않는다. 기존 일반 재화 사용 및 자원 보호 상한은 유지한다.
- 건조 `0회`는 완성 함선 수령 전용이며 새 건조를 제출하지 않는다. `1회`는 기존 소형 건조를 포함한다. 구동 중인 이전 GUI 캐시에서는 0회가 `Gacha.Amount.0`으로 표시될 수 있다.

## 일상 기능과 제외 범위

- 실기 확인된 기능: 의뢰 수령/재출항, 연구, 숙소, 일일 도전, META 지원, 개인 공간 상호작용. 상세 날짜·분기는 검증 문서를 따른다.
- 10/22 추가 통과: 어려움 11-4 세 회(잔여 3→0), 건조 0회 수령 전용, 후속 임무 보상 수령과 메인 복귀. 건조 횟수는 검증 후 기존 1회로 원복했다.
- 일반 출격 12-4, 작전문서 T1, 대형작전 일일, 기록 해역, 섬 식당은 이전 실기 기록이 있으나 현재 기본 운용에 임의로 추가 활성화하지 않는다.
- 섬 일반 생산/시즌 자동 연계는 한국 서버 구현 보호가 남아 있다. 보호를 삭제하거나 우회하지 않는다.
- 신규 개발도크 대상, 길드 공유 작전, 지휘냥 육성 대상/소비 범위는 별도 결정 대상이다.
- 요새·월간 보스는 함대 전투력/적응도 보호를 유지한다. 실패한 상태를 무리하게 반복하지 않는다.
- 드문 팝업, 월말 초기화 및 정확한 경합 조건은 발생 시 별도 확인한다. 오프라인 검사 통과와 실기 통과를 혼동하지 않는다.

최신 실기 결과: `KR_VALIDATION_2026-10-22.md`.

인계 시 ALAS는 실행 중이며 다음 정기 작업을 기다린다. 도크 부족 일괄퇴역은 기존 보호를 검사하고 연결했지만 이번 실행에서 도크가 차지 않아 새로 발동한 것은 아니다. 임무 목록 시간 초과 경고가 한 번 있었고 후속 수령은 성공했다. 동일 경고가 반복되면 오류 로그와 당시 화면으로 확인해야 한다.
