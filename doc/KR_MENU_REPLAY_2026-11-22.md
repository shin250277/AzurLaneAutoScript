# 한국 서버 메뉴 화면 검증 (2026-11-22)

실행 폴더의 한국 배포 브랜치에서 확인했다. 보관한 한국 게임 화면은 1280×720으로 정규화한 57장이다. 원본 화면은 로컬 Git 제외 경로에만 남기고, 저장소에는 판별에 필요한 버튼·제목 부분만 검은 배경에 남긴 이미지를 넣었다.

실행본의 UI.ui_page_appear로 43종의 메뉴에서 47개 양성 사례를 재생했다. 수정한 연습전·섬 지도·운송·창고 판별은 서로 다른 메뉴 표본에서도 오인되지 않는지 함께 검사했다. 도크 필터와 확인은 별도 Button.match 재생으로 검사했다. 이미지 변경은 이 여섯 항목뿐이다.

재생: `toolkit/python.exe -B -m dev_tools.kr_menu_page_replay log/kr_menu_capture_20261122`. 도크 창 전환 검사는 `dev_tools.kr_live_dock`에 원래 창 크기의 캡처 디렉터리를 지정한다.

메인 흰색은 한국 서버에서 별도 목적지가 아니라 메인 이동 버튼 집합이고, unknown은 실제 메뉴가 아니다. 별도 이벤트/SP, 연합전, 레이드 및 전용 RPG·병원 페이지는 이번 재생에 포함하지 않았다. 출격 메뉴의 이벤트 칸은 '이벤트 준비 중'이었다. 메뉴 인식은 전투·주문 제출·구매·수령 등 메뉴 내부 모든 작업의 성공을 뜻하지 않는다.
