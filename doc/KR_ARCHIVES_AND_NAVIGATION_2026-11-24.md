# 11월 24일 한섭 작전문서 및 메뉴 판별

## 사용 범위

Alas.exe에서 기존 한섭 프로필의 **작전문서**를 선택하고, ALAS의 해역 선택 목록에 있는 문서와 스테이지를 지정한다. 기존 함대·연료·도크 보호 설정은 그대로 사용한다. 문서 선택은 48종을 검사했으며, 48종을 모두 출격했다는 의미는 아니다. 한국 게임 목록에 보이지만 ALAS의 캠페인 사전에 없는 신규 문서는 자동 출격 지원으로 세지 않는다.

## 직접 캡처 및 수정

- 한국 클라이언트의 EX 31장, SP 22장 카드가 있는 목록을 직접 스크롤해 보관했다. ALAS가 지원하는 48종 + 사전 밖의 5종 + 잠김 표시 1칸을 구분했다.
- 실행 기준 0.85에 못 미친 12종만 한국어 배너로 교체했다. 별도 1종(GLORIOUS_BATTLE)은 인식됐지만 무작위 클릭 가능 영역이 카드 왼쪽 경계를 침범해 안쪽의 한국어 표본으로 교체했다. 기존 35종의 템플릿은 유지했다. 스크롤·출격·소비·클릭 로직은 변경하지 않았다.
- 카드별 양성·음성, 전체 화면에서 실행 코드가 실제로 돌려주는 클릭 사각형, 메인/출격 메뉴/작전문서 해역에서 잘못 반환하는 입구가 없는지까지 검사했다. 지원 48종, 비교 슬롯 54개, 불일치 0.
- 격창의 유니버스 SP1 지도에 실제 진입했다. 지도 확인과 데이터키 OCR 300/300 통과. 출격 없이 메인으로 복귀했다. 당일 일반 이벤트 출격 칸은 '이벤트 준비 중'이었다.
- 한섭 화면에서 섬 지도·섬 상점을 메인으로, 섬 상점을 일반 상점으로, 전술 교실을 학원으로도 인식하는 문제가 재현됐다. KR의 페이지 구분만 보완했다. 기존 43개 메뉴의 47장 각각을 등록된 모든 페이지 판별기와 대조해 유일한 정답 47/47을 확인했다. 다른 서버 변경 없음.
